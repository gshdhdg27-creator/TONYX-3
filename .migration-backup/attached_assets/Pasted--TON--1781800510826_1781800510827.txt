ВНИМАНИЕ, МАСШТАБНОЕ ОБНОВЛЕНИЕ ПРОФИЛЯ И ИНТЕГРАЦИЯ С БЛОКЧЕЙНОМ TON (ДЕПОЗИТЫ / АВТОВЫВОДЫ):

Реализуй следующие изменения в коде фронтенда и бэкенда:

1. РЕДИЗАЙН СТРАНИЦЫ ПРОФИЛЯ (UI):
   - Полностью удали все мелкие дублирующие плашки балансов сверху и сбоку экрана в профиле.
   - Оставь строго один главный, крупный блок под блоком информации пользователя (аватарка, имя, Telegram ID). Внутри этого блока должны отображаться только два баланса: сколько ТОН и сколько TONYX есть у пользователя.
   - Ниже балансов размести две кнопки: "Пополнить" и "Вывести".

2. АВТОМАТИЧЕСКОЕ ПОПОЛНЕНИЕ (DEPOSIT VIA TON CONNECT):
   - На фронтенде при клике на "Пополнить" добавь ввод суммы (минималка 0.1 TON) и интеграцию с TON Connect.
   - При подтверждении фронтенд вызывает sendTransaction на кошелек проекта, прикрепляя уникальный payload (комментарий, содержащий transaction_id или user_id).
   - Бэкенд: создай эндпоинт проверки платежа. Он должен запрашивать данные из блокчейна TON (через Toncenter API / TonAPI / RPC) по адресу кошелька проекта, искать транзакцию с указанным комментарием, валидировать сумму и автоматически зачислять TON на баланс пользователя в БД после успешной проверки.

3. ПОЛНОСТЬЮ АВТОМАТИЧЕСКИЙ ВЫВОД (AUTOMATED WITHDRAWAL):
   - При клике на кнопку "Вывести" открывается форма: поле для ввода суммы, поле для ввода TON-кошелька и кнопка, подписанная строго как "Вывод".
   - Бэкенд (POST /api/mini/wallet/withdraw): Сервер должен инициализировать кошелек проекта, используя секретную сид-фразу (мнемонику) из приватных переменных окружения (process.env.PROJECT_WALLET_MNEMONIC) с помощью пакетов @ton/ton и @ton/crypto.
   - При вызове эндпоинта бэкенд проверяет баланс пользователя в БД, списывает сумму внутри ACID-транзакции, а затем автоматически отправляет соответствующее количество TON с кошелька проекта на кошелек пользователя прямо через блокчейн. Присылай статус транзакции на фронтенд.

Проверь типы TypeScript через pnpm build, примени схему к базе данных и подготовь итоговый отчет по работе профиля и TON-скриптов!
