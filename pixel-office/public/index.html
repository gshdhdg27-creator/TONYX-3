OpenRouter · несколько бесплатных моделей

Один аккаунт для всех 12 ролей. Несколько ролей могут использовать одну модель. Офис использует только модели с нулевой ценой и пометкой :free.

  1. Создай аккаунт или войди в OpenRouter ↗
  2. Создай API-ключ в разделе Keys ↗
  3. Вставь ключ ниже. Покупать кредиты для этого офиса не нужно.

Ключ хранится только в памяти программы до её закрытия. Исходники, которые агент читает для задания, передаются выбранной модели через OpenRouter. .env и файлы ключей заблокированы, но не добавляй другие конфиденциальные данные в задания.

Groq · дополнительный Free-аккаунт

Qwen 3.8 и Llama могут быть доступны через Groq. Войти и создать ключ ↗

Офис не может проверить тариф через API. Не подключайте здесь ключ платного аккаунта. SiliconFlow отключён: нулевая цена нужных моделей не подтверждена.

GitHub · автоматическая отправка после аудита

Готовые изменения отправляются в отдельную ветку pixel-office/… репозитория TONYX-3. Основная ветка не перезаписывается.

Создать Fine-grained token ↗: только TONYX-3, Repository permissions → Contents: Read and write; Checks и Commit statuses: Read-only. Ключ этого чата не передаётся офису автоматически.

Vercel · деплой и проверка сайта

После отправки в GitHub офис ждёт деплой того же коммита, читает ошибки сборки и открывает сайт в мобильном браузере. До двух автоматических исправлений с повторным ревью. Изменения остаются в ветке задачи; публикация в основную версию сайта требует слияния в main.

Создать ключ Vercel ↗. Выбери команду проекта TONYX-3. Ключ остаётся только в памяти. Диагностика ошибок передаётся моделям для исправления; известные ключи скрываются.

Сейчас выбрана локальная копия TONYX-3. Файлы изменятся только после применения готового результата.

У каждой роли показаны запрошенная и фактическая модели. Замена не означает равное качество. Каталог обновляется; отсутствие квоты может остановить задачу.
